# Jelly Sumo

[English](README.en.md) | [日本語](README.jp.md)

柔らかいゼリーのようなキャラクター同士で、身体を押し合う3Dプロトタイプです。Godot 4.xで制作しています。

目的は、「身体を押し付けるとむにゅっと潰れ、離れるとぷるんと戻る」という感触が面白いかを試すことです。完成した対戦ゲームではなく、押し心地の検証に絞っています。

## できること

- ミント色のキャラクターを操作し、簡単なAIで動くオレンジ・紫の2体と押し合う
- 接触側の腹部がへこみ、横や縦へ少し膨らむ様子を見る
- 身体で相手を押して移動させる
- 離れると形が戻り、少し行き過ぎて揺れる動きを見る
- 台の端から落下する（落下後は自動復帰）

## 動作環境

- **確認済み：macOS / Godot 4.7.2 stable**
- レンダラー：Compatibility
- 操作：キーボード
- 外部アセット、追加プラグイン、.NET環境は不要です。

現在のプロジェクト設定はGodot 4.7で保存されています。ほかのGodotバージョンやOSでの動作は未確認です。

## 起動方法

1. このリポジトリをクローン、またはZIPでダウンロードして展開します。
2. Godotのプロジェクトマネージャーから **インポート** を選び、`project.godot` を指定します。
3. プロジェクトを開き、**F5（プロジェクトを実行）** を押します。

起動すると、すぐに3体の押し合いが始まります。

## 操作方法

| キー | 操作 |
| --- | --- |
| W / A / S / D | カメラの向きに合わせて前後左右へ移動 |
| R | 3体を初期位置へ戻す |

ミント色がプレイヤーです。相手の腹部に数秒間身体を押し付けてから、反対方向へ離れてみてください。圧縮、押し移動、揺れ戻りを続けて確認できます。

## 柔らかさの仕組み

押し移動には通常の`RigidBody3D`と球状の衝突形状を使っています。キャラクターは`SphereMesh`を組み合わせた簡単な形です。

腹部は、相手との距離と方向に応じてシェーダーで頂点を変形します。接触側をへこませ、横と縦へ少し膨らませます。変形量を減衰ばねで元に戻すことで、離れたときのオーバーシュートと揺れを表現しています。移動や衝突に合わせて上体も傾きます。

### 簡略化している点

- 衝突形状そのものは変形しません。本格的なSoft Bodyシミュレーションは使っていません。
- 圧縮量は接触付近の距離から推定しています。
- 複数方向から挟まれた場合は、最も強い接触方向を優先します。
- AIは近くの相手へ向かって押し、ときどき力を緩めるだけです。

タイトル画面、スコア、勝敗判定、キャラクター選択、音声、エフェクト、オンライン対戦は実装していません。

## ファイル構成

```text
.
├── project.godot           # プロジェクト設定
├── main.tscn               # 起動シーン
├── scripts/
│   ├── main.gd             # ステージ、カメラ、入力、キャラクター配置、操作説明
│   └── jelly.gd            # 移動、AI、圧縮ばね、上体の揺れ、復帰
├── shaders/
│   └── jelly.gdshader      # 腹部のへこみと膨らみ
└── tests/
    └── verify.gd           # 自動動作確認
```

Godotが生成する`.uid`ファイルもバージョン管理に含めます。再生成できる`.godot/`キャッシュは含めません。

## 押し心地の調整

| ファイル | 調整箇所 | 変わるもの |
| --- | --- | --- |
| `scripts/jelly.gd` | `SPRING` | 形が戻る速さ |
| `scripts/jelly.gd` | `DAMPING` | 揺れの収まりやすさ |
| `scripts/jelly.gd` | `apply_central_force`の力の値 | プレイヤーとAIの押す力 |
| `scripts/jelly.gd` | `pressure`の倍率 | 接触時の圧縮量 |
| `shaders/jelly.gdshader` | `deform`関数 | へこみと膨らみの形 |

## 自動動作確認

プロジェクトのルートディレクトリで実行します。`godot`コマンドがPATHに登録されている場合：

```sh
godot --headless --path . --script res://tests/verify.gd
```

macOSで`Godot.app`をApplicationsに配置している場合：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script res://tests/verify.gd
```

3体の生成、移動入力、相手の押し移動、双方の圧縮、離れた際のオーバーシュート、形の復元、落下と自動復帰の7項目を確認します。すべて成功すると`RESULT: 0 failures`が表示され、終了コード0で終了します。

この自動確認は動作と数値を検証するものです。描画や実際の押し心地は、通常起動して確認してください。
